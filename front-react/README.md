# Frontend React

Vite + React 19 + TypeScript, con React Router, PrimeReact 10, Tailwind CSS 4, Iconify y Zustand.

```bash
bun install        # o npm install
bun run dev        # http://localhost:3000
bun run build      # type-check + build en dist/
bun run preview    # sirve dist/ con wrangler
bun run deploy     # build + deploy a Cloudflare Workers
```

Consulta el README de la raíz del proyecto para más información.
